# PRD — vow

## 产品概述

vow 让任何带麦克风的浏览器设备（手机、平板）变身为宿主机的无线麦克风。宿主端启动 Web 服务后，移动端扫码或输入 URL 即可连接，选择 Hold 或 Tap 模式开始语音录制，音频通过 SSE 实时传输到宿主机后端。宿主机后端在系统中模拟一个虚拟音频输入设备，使任何桌面应用（Zoom、OBS、DAW 等）都能将其作为普通麦克风使用。

此外，页面提供"作为输出设备"选项——勾选后宿主机系统额外注册一个虚拟音频输出设备，手机端通过 Web Audio API 实时播放系统音频，实现"手机→宿主"和"宿主→手机"的双向音频通路。

## 用户故事

### P0 — 核心录制链路

1. **作为宿主用户**，我希望在宿主机启动服务后，手机能通过浏览器连接麦克风并实时传输音频，使 OBS/Zoom 等应用能直接用手机当作无线麦克风。
2. **作为手机用户**，我希望选择 Hold 模式（按住说话像对讲机）或 Tap 模式（点击开始、点击结束），以满足不同场景需求。
3. **作为宿主用户**，我希望系统能自动识别手机音频输入设备，无需手动配置。

### P1 — 反向音频输出

4. **作为宿主用户**，我希望勾选"作为输出设备"后，手机会播放宿主机的系统音频（如音乐、会议声音），实现手机变身监听设备。

### P2 — 连接体验

5. **作为手机用户**，我希望打开浏览器就能看到连接状态，无需安装 App。
6. **作为宿主用户**，我希望知道当前有几台设备已连接、各自的录制状态。

## 功能规格

### F1：录制模式

| 属性 | 值 |
|------|-----|
| Hold 模式 | 用户长按录制按钮时录音，松开停止 |
| Tap 模式 | 用户点击按钮开始/停止，状态翻转 |
| 采样率 | 默认 44100 Hz，可配置 |
| 音频格式 | Web Audio PCM → base64 → SSE |

### F2：SSE 实时传输

- 客户端通过 `/api/sse` 建立 SSE 连接
- 每个音频 chunk 包含：id、data（base64 PCM）、sampleRate、timestamp
- 服务端接收后写入虚拟音频设备缓冲区

### F3：虚拟音频设备

- **输入设备**：创建虚拟麦克风，系统可见为 `Web Mic Input`
- **输出设备**：可选创建虚拟扬声器，系统可见为 `Web Mic Output`
- 实现方案：Windows 使用 Core Audio API / WASAPI；跨平台考虑使用 `node-speaker` + 虚拟音频驱动

### F4：Web 界面

- 连接状态指示（已连接 / 未连接）
- 录制模式切换（Hold / Tap）
- 录制按钮（Hold 模式按压力感应）
- "作为输出设备"复选框
- 音量指示条（实时反馈麦克风输入电平）
